## 2. Historia de usuario según Jira

Como usuario de SmartList,
quiero tener una interfaz visual más organizada y adaptable,
para gestionar mis listas de compras de forma más clara y sencilla desde cualquier dispositivo.

## 3. Criterios de aceptación según Jira

* La lista de productos debe tener una presentación visual mejorada.
* Los botones deben ser claros y fáciles de identificar.
* Los estados Pendiente y Comprado deben diferenciarse visualmente.
* La interfaz debe adaptarse correctamente a dispositivos móviles y computadores.
* Los cambios visuales no deben afectar las funcionalidades existentes.
* La aplicación debe continuar funcionando correctamente.
